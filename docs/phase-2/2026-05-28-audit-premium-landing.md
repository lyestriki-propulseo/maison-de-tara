# Audit premium — Landing Page Maison de Tara (V1 existante)

_Date : 28 mai 2026_

## 1) Synthèse exécutive

La base actuelle est solide (lisible, narrative, accessible), mais le rendu premium peut fortement progresser sur **4 leviers** :

1. **Clarté immédiate (10 secondes)** : expliciter l’offre au-dessus de la ligne de flottaison.
2. **Direction visuelle propriétaire** : le block print doit devenir un système, pas un accent ponctuel.
3. **Conversion douce mais ferme** : rassurer et guider vers la réservation sans agressivité.
4. **Architecture éditoriale “moins mais mieux”** : réduire la densité perçue section par section.

---

## 2) Contraintes business à respecter (issues des échanges Tara)

- Objectif principal : conversion en réservation en 10–15 secondes.
- Positionnement : simple, élégant, premium, non “too much”.
- Offre hybride : atelier céramique + café + boutique maison déco.
- Réservation : sessions 2h, anti-no-show (empreinte/caution logique), pas de prix affichés en dur.
- Contenu visuel réel disponible plus tard (septembre) → besoin d’un système graphique fort sans photos finales.
- Besoin moyen terme : workshops/événements calendrier, bons cadeaux, kits “Take Home”.

## 3) Audit poussé de l’existant (forces / risques / actions)

## 3.1 Hero + réservation

**Forces**
- Hero avec univers (tabs) déjà pertinent.
- CTA réservation présent rapidement.
- Ton de marque poétique.

**Risques premium/conversion**
- Proposition de valeur pas assez “factuelle” immédiatement.
- Signaux de réassurance (durée, fonctionnement, no-show policy) encore diffus.
- Tabs intéressants, mais différenciation visuelle encore limitée.

**Actions recommandées**
- Ajouter une phrase utilitaire claire sous H1 : “Atelier de peinture sur céramique, café & boutique à La Garenne-Colombes”.
- Ajouter 3 preuves courtes visibles sans scroll.
- Ajouter micro-copy sécurité sur réservation (paiement sécurisé / acompte no-show).

## 3.2 Section concept / storytelling

**Forces**
- Bonne matière narrative.
- Intention “maison vivante” cohérente.

**Risques**
- L’éditorial peut sembler long si l’utilisateur veut juste réserver.
- Le “pourquoi Tara” n’est pas encore assez incarné.

**Actions**
- Raccourcir le bloc texte principal.
- Créer une capsule “Mot de Tara” (2–4 phrases max).

## 3.3 Univers (atelier/café/boutique)

**Forces**
- Structure en cartes compréhensible.

**Risques**
- Peut ressembler à une grille de services standard.
- Hiérarchie parfois équivalente entre éléments (manque de focal point).

**Actions**
- Limiter à 3 bénéfices forts par univers.
- Renforcer signatures visuelles propres à chaque univers (accent, motif, icône, texture).

## 3.4 “Comment ça se passe”

**Forces**
- Section indispensable au secteur.

**Risques**
- Peut devenir trop procédural si trop détaillé.

**Actions**
- Passer en parcours 3 étapes ultra-lisible.
- Ajouter note “pas de prix en ligne / infos sur place” selon stratégie voulue.

## 3.5 Événements / calendrier

**Forces**
- Aligné avec besoin business (partenariats, décembre, offres dédiées).

**Risques**
- Confusion si section café concurrente au calendrier.

**Actions**
- Clarifier la logique de navigation : “Atelier / Événements / Boutique”.
- Mettre un mini-calendrier éditorial (teaser) + bouton “Voir tous les ateliers”.

## 3.6 Localisation / contact

**Forces**
- Présence d’une section contact/localisation.

**Risques**
- SEO local pas assez exploité naturellement.

**Actions**
- Intégrer formulations locales dans les titres/sous-titres.
- Clarifier accès/horaires/réservation en un bloc lisible mobile.

## 3.7 Galerie / journal / newsletter

**Forces**
- Bonnes sections de réassurance et fidélisation.

**Risques**
- Sans photos finales, risque d’effet “placeholder”.

**Actions**
- Transformer temporairement la galerie en “mood fragments” (matières, dessins, motifs, objets).
- Newsletter : proposition de valeur explicite (invites, workshops, ouverture de créneaux).

## 4) 4 variantes premium par section (à choisir)

## Section A — Header / navigation

1. **A1 — Quiet Luxury Sticky** : header fin, fond ivoire, bouton réservation plein à droite.
2. **A2 — Editorial Ribbon** : topbar éditoriale (ouverture automne, localisation), nav minimaliste.
3. **A3 — Split Navigation** : logo centré, liens gauche/droite, CTA fixe.
4. **A4 — Progressive Header** : discret au chargement puis devient plus compact au scroll.

## Section B — Hero

1. **B1 — Hero Clarté Immédiate** : H1 poétique + sous-ligne factuelle + 3 preuves.
2. **B2 — Hero Signature Tara** : message fondatrice + CTA principal + CTA secondaire “Découvrir le concept”.
3. **B3 — Hero 3 Univers dynamiques** : changement visuel fort selon tab (accent + motif + micro-copy).
4. **B4 — Hero Réservation First** : colonne gauche marque, colonne droite module réservation enrichi.

## Section C — Module réservation

1. **C1 — Minimal Trust** : formulaire court + garanties sécurité + no-show policy claire.
2. **C2 — Step-by-step** : 3 étapes compactes (créneau, participants, coordonnées).
3. **C3 — Concierge** : ton “on vous prépare la table”, plus chaleureux.
4. **C4 — Mobile Sticky CTA + Drawer booking** : CTA fixe mobile ouvrant un panneau propre.

## Section D — Concept / histoire

1. **D1 — Founder Note** : carte “Mot de Tara”, très éditoriale.
2. **D2 — Dual Culture** : split visuel Inde x France avec micro-récit.
3. **D3 — Timeline douce** : 4 jalons (idée, lieu, ouverture, communauté).
4. **D4 — Manifesto court** : 5 lignes max, très premium, sans surcharge.

## Section E — Univers (Atelier/Café/Boutique)

1. **E1 — Trio cartes premium** : 3 cartes homogènes, 1 CTA par carte.
2. **E2 — Alternance immersive** : sections alternées image/texte pour plus de respiration.
3. **E3 — Accordéon éditorial** : une carte ouverte à la fois (moins dense).
4. **E4 — Carousel mobile + grid desktop** : ergonomie différenciée selon device.

## Section F — Comment ça marche

1. **F1 — 3 étapes iconiques** : Choisir / Créer / Récupérer.
2. **F2 — Carte parcours client** : expérience de bout en bout (arrivée → cuisson).
3. **F3 — FAQ micro** : 6 questions clés (durée, cuisson, annulation, etc.).
4. **F4 — Process + trust badges** : rapide + rassurant (sécurité, anti-surbooking).

## Section G — Événements / calendrier

1. **G1 — Agenda teaser** : 3 événements du mois + lien calendrier complet.
2. **G2 — Grille mensuelle** : mini calendrier visuel premium.
3. **G3 — Focus saisonnier** : bloc “Décembre créatif” (partenariats/cadeaux).
4. **G4 — Segmentation d’offres** : Ateliers réguliers / Workshops / Privatisations.

## Section H — Localisation / contact

1. **H1 — Local SEO élégant** : titre géolocalisé + plan + horaires.
2. **H2 — Contact Concierge** : téléphone et message “réponse sous X h”.
3. **H3 — Visit card** : carte “venir nous voir” très visuelle.
4. **H4 — Mobile first practical** : gros boutons appeler/réserver/itinéraire.

## Section I — Newsletter / fidélisation

1. **I1 — Club Maison de Tara** : invitations et actus en avant-première.
2. **I2 — Agenda insider** : alertes créneaux et workshops.
3. **I3 — Gift & Take Home updates** : nouveautés cadeaux/kits.
4. **I4 — Soft opt-in** : formulaire discret + preuve sociale locale.

## 5) Direction artistique premium (sans photos finales)

## Palette (base)
- Ivoire chaud (fond), terre cuite douce (accents), laiton mat (micro-détails), charbon (texte), vert sauge grisé (touches).

## Motifs block print
- Motif principal tulipe/floral (faible opacité 4–8%).
- Motif secondaire géométrique pour séparateurs.
- Règle : 1 motif fort par viewport max.

## Typographie
- Serif expressive pour titres (modérée).
- Sans-serif élégante pour texte utilitaire.
- Échelle stable : éviter trop de tailles proches.

## Micro-interactions
- Hover subtil (1–2 px, opacité/transparence).
- Durées 180–260ms.
- Pas d’animations décoratives trop nombreuses.
