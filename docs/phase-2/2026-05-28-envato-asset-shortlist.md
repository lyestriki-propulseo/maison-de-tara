# Shortlist Envato — Maison de Tara

Date : 28 mai 2026

Objectif : constituer une base d'assets premium pour 4 landing pages finales, avec vert comme couleur principale, direction artisanale chaleureuse, et touches indiennes block print.

## Regles de selection

- Vert sauge / olive / profond comme couleur dominante.
- Chaleur artisanale avant effet "coffee shop".
- Adultes, mains, matieres, tables, objets, lumiere chaude.
- Pas d'atelier enfantin trop colore.
- Pas de concept store industriel.
- Pas de photo e-commerce agressive.
- Pas de luxe hotelier froid.

## Assets locaux deja disponibles

Dossier :
`Envato/Indian_Traditional_Ornament_Muhgal_Kalamkari_Seamless_Patterns`

Contenu :
- 12 JPG 4262x4262
- 12 PNG transparents 4262x4262
- sources AI / EPS / PAT

Usages recommandes :
- fonds a 4-8% d'opacite
- panneaux lateraux hero
- fond newsletter
- fond section boutique
- transitions entre sections

Patterns a privilegier :
- `_11` ou `_9` : doux, lumineux, bons pour hero / sections claires
- `_3` ou `_5` : plus vivant, bon pour "Maison vivante"
- `_10` : dense, bon pour boutique / galerie
- motifs bleus : a eviter comme dominante, possible en micro-detail
