# Tranche 1 — Socle V3 · Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Échafauder une app TanStack Start + Supabase déployable, avec une coquille d'admin protégée par authentification, la CI, et le déploiement Coolify.

**Architecture:** Une seule app React/TanStack Start (SSR via Nitro) sert le site public ET l'admin. Supabase fournit Postgres + Auth + Storage. Les variables d'env sont validées au démarrage (Zod). L'admin est une zone de routes protégée par session Supabase (garde côté client suffisante au lancement ; les données sont protégées côté serveur par RLS + service-role).

**Tech Stack:** TanStack Start 1.168, React 19.2, TypeScript 5.9 strict, Tailwind v4, Vitest 4.1, Supabase CLI 2.109, @t3-oss/env-core, Docker + Coolify.

## Global Constraints

- **Node 24** (Active LTS) · **pnpm 11.9.0** (`"packageManager": "pnpm@11.9.0"`, `.nvmrc` = `24`).
- **TypeScript strict, JAMAIS `any`** — `unknown` puis narrowing, ou typer correctement.
- **Path aliases `@/*` obligatoires** — pas d'import relatif `../../`.
- **Max ~200 lignes par fichier** — au-delà, découper.
- **Type check après chaque modif** : `pnpm tsc --noEmit`. Tâche non terminée si type check OU tests échouent.
- **Aucun secret commité** : clés Supabase / Monetico / Brevo → `.env` (gitignoré), jamais dans le code.
- **FR** partout dans l'UI. Pas de styles inline (Tailwind uniquement).
- **Commits séparés par changement logique**, conventions `feat:`/`chore:`/`test:`…

```ts
import type { Session } from '@supabase/supabase-js'
import { supabaseBrowser } from '@/lib/supabase/browser'

export async function signIn(
  email: string,
  password: string,
): Promise<{ session: Session | null; error: string | null }> {
  const { data, error } = await supabaseBrowser().auth.signInWithPassword({ email, password })
  return { session: data.session, error: error?.message ?? null }
}

export async function signOut(): Promise<void> {
  await supabaseBrowser().auth.signOut()
}

export async function getSession(): Promise<Session | null> {
  const { data } = await supabaseBrowser().auth.getSession()
  return data.session
}
```

- [ ] **Step 5: Créer la page de login**

`app/src/routes/login.tsx` :

```tsx
import { createFileRoute, useNavigate } from '@tanstack/react-router'
import { useState } from 'react'
import { signIn } from '@/lib/auth'

export const Route = createFileRoute('/login')({ component: LoginPage })

function LoginPage() {
  const navigate = useNavigate()
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [error, setError] = useState<string | null>(null)

  async function onSubmit(e: React.FormEvent) {
    e.preventDefault()
    setError(null)
    const { error } = await signIn(email, password)
    if (error) return setError(error)
    navigate({ to: '/admin' })
  }

  return (
    <form onSubmit={onSubmit} className="mx-auto mt-24 flex max-w-sm flex-col gap-4">
      <h1 className="text-xl">Administration — Maison de Tara</h1>
      <input className="border p-2" type="email" placeholder="Email" value={email}
        onChange={(e) => setEmail(e.target.value)} required aria-label="Email" />
      <input className="border p-2" type="password" placeholder="Mot de passe" value={password}
        onChange={(e) => setPassword(e.target.value)} required aria-label="Mot de passe" />
      <button className="bg-black p-2 text-white" type="submit">Se connecter</button>
      {error && <p role="alert" className="text-red-600">{error}</p>}
    </form>
  )
}
```
